# Krista Managed Cases Extension for Krista

## Overview

The **Krista Managed Queue** extension manages customer support cases by connecting end users with support agents based on role-based queue assignments. It provides a complete case orchestration solution within the Krista ecosystem.

## Key Features

- **Role-Based Queue Management**: Assign and manage support queues based on agent roles
- **Task Lifecycle Management**: Create, join, leave, and submit tasks
- **Multi-Channel Support**: Handle cases from various communication channels
- **Routing Intelligence**: Route tasks to appropriate queues based on routing information

## Quick Start

1. [Configure the Extension](pages/ExtensionConfiguration.md)
2. Set up agent roles in Krista Studio
3. Start using catalog requests in your conversations
